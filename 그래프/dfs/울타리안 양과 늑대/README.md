문제
R×C 크기의 목장 지도가 있다. 각 칸은 아래 중 하나다.

. : 빈 땅
# : 울타리 (지나갈 수 없음)
o : 양 한 마리
v : 늑대 한 마리

울타리가 아닌 칸끼리 **상하좌우(4방향)**로 이어져 있으면 같은 영역이다. 대각선은 연결로 보지 않는다. 영역마다 아래 규칙대로 싸움이 일어난다.

영역 안의 양 수가 늑대 수보다 많으면 늑대가 모두 죽고 양만 남는다.
그 외(양이 적거나 같을 때)에는 양이 모두 죽고 늑대만 남는다.

모든 영역의 싸움이 끝난 뒤 살아남은 양과 늑대의 총 수를 구해라.

입력

첫째 줄: R, C (1 ≤ R, C ≤ 250)
다음 R줄: 길이 C인 문자열 (., #, o, v로만 구성, 공백 없음)

출력

살아남은 양의 수와 늑대의 수를 공백으로 구분해서 출력

예시 1
```
입력
7 9
#########
#o.o.#v.#
#.v..#.o#
#########
#v..#...#
#.o.#.o.#
#########

출력
3 2

```


예시 2
```

입력
1 3
o.v

출력
0 1
```

예시 3
```

입력
2 2
##
##

출력
0 0
```

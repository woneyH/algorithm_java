Given a string s, return the string after replacing every uppercase letter with the same lowercase letter.

 

Example 1:

Input: s = "Hello"
Output: "hello"

<br>
Example 2:

Input: s = "here"
Output: "here"

<br>
Example 3:

Input: s = "LOVELY"
Output: "lovely"


---
